# Registration Form

A simple registration form built using HTML, CSS, and JavaScript with real-time form validation.

## Live Demo

[View live.](https://anishams10.github.io/login_form/)
## Features

* **Name Validation:** Displays an error message if the name field is empty.
* **Email Validation:** Checks whether the email address is in a valid format.
* **Password Validation:** Ensures the password contains at least 6 characters.
* **Real-Time Validation:** Validates the input fields as the user types.
* **Submit Button Control:** Keeps the submit button disabled until all fields are valid.
* **Error Messages:** Displays appropriate error messages for invalid inputs.

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use the Live Server extension.
4. Enter your name, email, and password to test the form validation.
